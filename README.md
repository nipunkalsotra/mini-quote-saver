# 💭 Mini Quote Saver

A simple and beautiful web app to save and organize your favorite quotes using localStorage.

## ✨ Features

- **Add Quotes** - Save quotes with categories
- **Categories** - Organize quotes (Inspirational, Funny, Motivational, Life, Other)
- **Favorites** - Star your favorite quotes
- **Edit** - Modify quotes inline
- **Filter** - View quotes by category or favorites
- **Word Count** - Track total words across all quotes
- **Persistent Storage** - Quotes saved in browser localStorage

## 🚀 Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. Start adding quotes!

## 💡 Usage

- Select a category and type your quote
- Click "Add Quote" or press Enter
- Use ⭐ to mark favorites
- Click ✏️ to edit any quote
- Filter quotes using the category buttons
- All quotes are automatically saved
